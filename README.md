Event Registration Form using HTML, CSS, PHP, and phpMyAdmin

This project is a simple Event Registration Form that allows users to register for an event. The form captures user information and stores it in a MySQL database managed via phpMyAdmin. The backend logic is implemented using PHP.

Features

User-friendly form for event registration.

Input validation using HTML and PHP.

Stores form data in a MySQL database.

Simple and clean UI using CSS.

Requirements

XAMPP or MAMP (to set up a local server and phpMyAdmin)

Web Browser (Google Chrome, Mozilla Firefox, etc.)

Code Editor (VS Code, Sublime Text, etc.)
